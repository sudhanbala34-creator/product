# Product and Category Management System

## Project Description

This project is a simple DBMS project using **MySQL**.

It contains two tables:

* Category
* Product

The Product table is connected to the Category table using a **Foreign Key**.

## Tables

### Category

* category_id
* category_name

### Product

* product_id
* product_name
* price
* category_id

## Operations Performed

1. Create Category and Product tables
2. Insert sample data
3. Display products with their categories
4. Count products in each category
5. Find the highest-priced product in each category
6. Display categories having more than 5 products
7. Find average product price category-wise
8. Perform CRUD operations

## CRUD Operations

* **Create** – Insert new product
* **Read** – Display product data
* **Update** – Change product price
* **Delete** – Remove a product

## Software Used

* MySQL
* MySQL Workbench

## Conclusion

This project demonstrates basic SQL commands, table relationships, aggregate functions, JOIN, GROUP BY, HAVING, and CRUD operations.
